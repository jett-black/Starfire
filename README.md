# Starfire

Companion launcher for **The Hidden Ones**: the Starfire Lite Chinese → English translation overlay, the game and UU Booster —
one at a time or all at once.

## Download
Get the newest **Starfire-Vx.x.zip** from [Releases](../../releases/latest), unzip it into a permanent folder and run
`Starfire.exe`. After that, Starfire updates itself: it checks this page when it opens and offers an **UPDATE** button.

## Requirements
* Windows 10 / 11
* Windows' Chinese (Simplified) text recognition (OCR) — Starfire installs it on first start if it is missing.
